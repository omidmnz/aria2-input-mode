#+title: Major Mode for Aria2 Input Files

A major mode based on =outline-mode= for Aria2's [[https://aria2.github.io/manual/en/html/aria2c.html#input-file][input files]].

* Installation
You can install it using the following recipe:
#+begin_src emacs-lisp
  (use-package quint-ts-mode
    :vc (:url "https://github.com/omidmnz/aria2-input-mode.git"))
#+end_src

To use it, you can simply use the following line as the first line in
your file:
#+begin_quote
### -*- mode: aria2-input; -*-
#+end_quote

* Features
Syntax highlighting and basic auto-completion is provided for the
documented options, as well as hash names in =checksum=<hash-name>=.

The hash values are only highlighted when the hash value matches the
format, e.g. 40 hex digits for =sha-1=, 32 hex digits for =md5=, etc. You
can use the following to see the available hash algorithms for your
installed version:
#+begin_src bash :results list :cache yes
  aria2c -v | grep "Hash Algorithms" | cut -d: -f2 | sed -Ee 's/^ +//g' -e 's/ +/\n/g' | sed -Ee 's/,$//'
#+end_src
